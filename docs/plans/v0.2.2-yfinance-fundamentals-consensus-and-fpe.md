## 1. Objective & Background

This plan specifies the institutional calibration of **Forward P/E (`forward_pe`)** and the addition of **GAAP vs. Non-GAAP distortion detection** in the `ohmydata.providers.yfinance` fundamentals pipeline.

### 1.1 The Problems in Yahoo Finance Raw Fundamentals
Downstream consumers (such as Stock Notify and tactical equity analysts) identified two critical valuation anomalies when consuming raw Yahoo Finance objects:

1. **Raw `forwardPE` Anchoring to FY2 (+1y) Instead of FY1 (0y)**:
   - Yahoo's precomputed `info.get("forwardPE")` often anchors strictly to the out-year fiscal consensus (+1y).
   - For high-growth or normalizing cyclical tech leaders, this creates massive discrepancies against institutional terminals (Bloomberg, FactSet, Tiger Brokers):
     - **NVDA**: Raw Yahoo `forwardPE = 14.9x` (anchoring to FY28 \$15.46), whereas Tiger Brokers, FactSet, and sell-side consensus report **24.8x** (anchoring to current FY27 \$9.28).
     - **GOOGL**: Raw Yahoo `forwardPE = 22.8x` (anchoring to FY27 \$14.84), whereas Tiger Brokers and FactSet report **16.4x** (anchoring to current FY26 \$20.60).
     - **AMZN**: Raw Yahoo `forwardPE = 26.2x`, whereas Tiger Brokers reports **20.6x**.

2. **Unadjusted GAAP Consensus Distortions (e.g. Spin-offs and M&A Gains)**:
   - In Yahoo Finance, `earnings_estimate` (`0y.avg`) frequently reflects unadjusted GAAP consensus, which includes one-off non-recurring accounting windfalls.
   - **Case Study — GE Vernova (`GEV`)**:
     - In 2026Q1, GEV recognized a **\$17.44** one-off gain resulting from its spin-off from General Electric.
     - Yahoo's sell-side consensus table reported an unadjusted GAAP consensus EPS of **\$30.74**, yielding a misleadingly low apparent Forward P/E of **30.6x**.
     - Meanwhile, institutional core operating (Non-GAAP) consensus EPS is **\$15.15 ~ \$18.29**, yielding a true operating Forward P/E of **51.5x ~ 62x** (as displayed on Tiger Brokers).
   - Without algorithmic detection, algorithmic screeners fall into a "false value trap" on distorted tickers.

### 1.2 Architectural Goal in OMD
Instead of forcing every downstream consumer (`stock_notify`, `funmoney_backtest`, etc.) to repeatedly write ad-hoc valuation patch scripts, **Oh My Data (OMD)** will ingest, calibrate, validate, and preserve these fields at the provider abstraction layer, strictly adhering to OMD's non-negotiable invariants.

### 3.1 `YFinanceValuationSnapshot` Updates
Preserve the raw provider-native value while providing the calibrated standard value:

```python
@dataclass(frozen=True)
class YFinanceValuationSnapshot:
    """Snapshot of valuation ratios and market size."""

    trailing_pe: float | None = None
    forward_pe: float | None = None  # Calibrated FY1 institutional Forward P/E
    raw_forward_pe: float | None = None  # Provider-native raw value from info.get("forwardPE")
    forward_pe_source: str | None = None  # "FY1_CONSENSUS" | "RAW_FALLBACK" | None
    peg_ratio: float | None = None
    price_to_sales: float | None = None
    forward_eps: float | None = None  # Calibrated FY1 forward EPS (or raw if uncalibrated)
    raw_forward_eps: float | None = None  # Provider-native raw value from info.get("forwardEps")
    market_cap: float | None = None
    enterprise_value: float | None = None
    shares_outstanding: float | None = None
    currency: str | None = None
```

### 3.2 `YFinanceAnalystEstimates` Updates
Add Non-GAAP current year consensus and algorithmic relative gap measurement:

```python
@dataclass(frozen=True)
class YFinanceAnalystEstimates:
    """Analyst consensus estimates across horizons and Non-GAAP cross-validation."""

    revenue_est_current_q: float | None = None
    revenue_est_next_q: float | None = None
    revenue_est_current_y: float | None = None
    revenue_est_next_y: float | None = None
    eps_est_current_q: float | None = None
    eps_est_next_q: float | None = None
    eps_est_current_y: float | None = None  # Sell-side consensus 0y.avg (often GAAP in Yahoo)
    eps_est_next_y: float | None = None  # Sell-side consensus +1y.avg
    eps_current_year: float | None = (
        None  # Core operating consensus from info.get("epsCurrentYear") (Non-GAAP)
    )
    gaap_diff_pct: float | None = None  # Relative deviation: |eps_0y - eps_current_y| / min
    has_gaap_distortion: bool = False  # True when gaap_diff_pct > 0.25
```

## 4. Implementation Specification

File: `src/ohmydata/providers/yfinance/fundamentals.py`

### 4.1 Calibration Engine inside `parse_symbol_fundamentals`

The parsing logic in `parse_symbol_fundamentals` must execute the following structured steps:

#### Step 1: Raw Extraction
```python
raw_forward_pe = _safe_float(info.get("forwardPE"))
raw_forward_eps = _safe_float(info.get("forwardEps"))
eps_current_year = _safe_float(info.get("epsCurrentYear"))
```

#### Step 2: Derive Implied Price
Because `fast_info` or `info` may not always contain a single canonical price attribute across international symbols, derive `implied_price` defensively:
```python
implied_price = None
if (
    raw_forward_pe is not None
    and raw_forward_eps is not None
    and raw_forward_pe > 0
    and raw_forward_eps > 0
):
    implied_price = raw_forward_pe * raw_forward_eps
elif trailing_pe is not None and deps_latest is not None and trailing_pe > 0 and deps_latest > 0:
    implied_price = trailing_pe * deps_latest
elif market_cap is not None and shares_outstanding is not None and shares_outstanding > 0:
    implied_price = market_cap / shares_outstanding
```

#### Step 3: Calibrate FY1 Forward P/E
Extract `eps_0y = estimates.eps_est_current_y`.
Check for currency/share-class unit mismatch (e.g. ADRs where EPS is quoted in CNY/HKD but price in USD):
```python
calibrated_fpe = raw_forward_pe
calibrated_feps = raw_forward_eps
fpe_source = "RAW_FALLBACK" if raw_forward_pe is not None else None

if implied_price is not None and eps_0y is not None and eps_0y > 0:
    is_mismatched = False
    if raw_forward_eps is not None and raw_forward_eps > 0:
        ratio = eps_0y / raw_forward_eps
        if ratio > 3.0 or ratio < 0.25:
            is_mismatched = True

    if not is_mismatched:
        calibrated_fpe = round(implied_price / eps_0y, 4)
        calibrated_feps = round(eps_0y, 4)
        fpe_source = "FY1_CONSENSUS"
```

#### Step 4: GAAP vs. Non-GAAP Distortion Detection
Perform pure relative deviation calculation:
```python
gaap_diff_pct = None
has_gaap_distortion = False

if eps_0y is not None and eps_current_year is not None and eps_0y > 0 and eps_current_year > 0:
    denom = min(eps_0y, eps_current_year)
    if denom > 0:
        gap = abs(eps_0y - eps_current_year) / denom
        gaap_diff_pct = round(gap, 4)
        if gap > 0.25:
            has_gaap_distortion = True
```
