# v0.1.0 Slice 3 — Availability Evidence

Status: **READY_FOR_EXECUTION**

Parent plan: [`v0.1.0-pit-market-facts.md`](v0.1.0-pit-market-facts.md)

## Objective

Add a small provider-independent value contract that distinguishes source-side
availability evidence from OMD observation and current fetch time. The object
is dataframe-free, storage-free, JSON-safe, and fail-closed. It is intended for
later endpoint-specific raw-fact metadata; it is not itself a universal fact
row or a PIT guarantee.

## Public API

Add and export from `ohmydata.core`:

```python
AvailabilityBasis
AvailabilityPrecision
AvailabilityEvidence
```

### Enums

```text
AvailabilityBasis:
  SOURCE_DECLARED
  INFERRED_SCHEDULE
  PROVIDER_FIRST_OBSERVED
  UNKNOWN

AvailabilityPrecision:
  TIMESTAMP
  DATE
  UNKNOWN
```

`SESSION` is deliberately excluded: canonical sessions and
`first_usable_session` remain consumer-owned.

### AvailabilityEvidence

Frozen fields:

```text
source_available_at: datetime | date | None
provider_first_observed_at: datetime
snapshot_fetched_at: datetime
availability_basis: AvailabilityBasis
availability_precision: AvailabilityPrecision
```

All datetimes must be timezone-aware and are normalized to UTC. A `date` value
must be a real `date` whose concrete type is not `datetime`.

## Valid State Matrix

The only valid source evidence combinations are:

| basis | precision | source_available_at |
|---|---|---|
| `SOURCE_DECLARED` | `TIMESTAMP` | aware `datetime` |
| `SOURCE_DECLARED` | `DATE` | `date` |
| `INFERRED_SCHEDULE` | `TIMESTAMP` | aware `datetime` |
| `INFERRED_SCHEDULE` | `DATE` | `date` |
| `PROVIDER_FIRST_OBSERVED` | `UNKNOWN` | `None` |
| `UNKNOWN` | `UNKNOWN` | `None` |

All other combinations fail with `ValueError`. Raw strings instead of enum
members fail with `TypeError`.

`snapshot_fetched_at` must be greater than or equal to
`provider_first_observed_at`. Backdated current fetch evidence fails with
`ValueError`.

No ordering requirement is imposed between `source_available_at` and provider
observation time. Endpoint-specific plausibility checks must not be silently
corrected by core.

## Derived Properties

Expose:

```python
availability_anchor: datetime | date | None
pit_proven: bool
```

`availability_anchor` returns source evidence for `SOURCE_DECLARED` and
`INFERRED_SCHEDULE`, provider first observation for
`PROVIDER_FIRST_OBSERVED`, and `None` for `UNKNOWN`.

`pit_proven` is `True` only for `SOURCE_DECLARED` with `TIMESTAMP` precision.
It is `False` for date-only declarations, inferred schedules, first-observed
fallback, and unknown evidence. It does not mean a strategy could use the fact
in a particular session.

## Construction from Snapshot Observation

Provide:

```python
AvailabilityEvidence.from_observation(
    store: SnapshotStore,
    observation: SnapshotObservationRef,
    *,
    source_available_at: datetime | date | None = None,
    availability_basis: AvailabilityBasis = AvailabilityBasis.PROVIDER_FIRST_OBSERVED,
    availability_precision: AvailabilityPrecision = AvailabilityPrecision.UNKNOWN,
) -> AvailabilityEvidence
```

The factory must validate the observation by calling
`store.replay_observation(observation)`. It derives first-observed time from the
validated replay manifest's legacy `retrieved_at` field and current fetch time
from the now-validated observation ref. It must not reconstruct paths itself,
trust a caller-forged observation, call a provider, or deserialize payload
bytes. Tampered receipts or linked snapshots raise `SnapshotIntegrityError`.

## Serialization

`to_dict()` returns a fresh JSON-safe object with exactly:

```text
source_available_at
provider_first_observed_at
snapshot_fetched_at
availability_basis
availability_precision
pit_proven
```

Datetimes use UTC ISO-8601 with `Z`, preserving non-zero microseconds; dates
use `YYYY-MM-DD`; `None` remains JSON null; enums use the uppercase values
above. Repeated calls return independent dictionaries.

All tests are offline and synthetic. Cover:

- every valid state in the matrix and all invalid combinations;
- raw string enums, naive datetimes, datetime-as-date confusion, invalid value
  types, and backdated current fetch;

- exact independent `to_dict()` output and JSON serialization;
- `from_observation()` for first and later unchanged observations;
- revised payload with a distinct first-observed time;
- tampered observation ref, receipt, and linked snapshot failure;
