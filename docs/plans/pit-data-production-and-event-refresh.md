## 2. 最小数据契约

| 逻辑数据集 | 必要身份/字段 | 说明 |
| --- | --- | --- |
| instrument identity | instrument_id、issuer_id/CIK、证券类别、交易所、币种、有效期 | ticker只是可变别名；多股类/ADR不等于同一证券 |
| daily bars | instrument_id、session_date、OHLCV、币种、source、版本、availability | 原始行情与复权因子分开；公司行动保留当时可知版本 |
| financial facts | issuer_id、concept、statement、period_start/end、instant/duration、dimensions、unit_native、currency、value、accession | 单季/YTD/FY不可仅凭结束日合并 |
| estimates/KPI | issuer_id/instrument_id、metric、forecast horizon/period、as_of、定义、口径、单位、来源版本 | 与已报告actuals物理或类型隔离；一致预期保留每日/变更快照 |
| derived metrics | instrument_id、valuation_at、metric、value/unit、input version IDs、recipe_version、availability/quality | 不直接把当前latest回填历史 |
| quality/correction | finding_id、input version、规则/解析版本、状态、检测/裁决时间、证据、supersedes | 与事实分离；不得覆盖原值 |

金额为Decimal/整数；比例为有单位、有容差的有限浮点数。保留原始payload和单位，
标准化值通过有版本的转换产生，缺值不填0。合并口径、税前税后、GAAP/non-GAAP分列。
字段缺失、源未披露、解析失败、冲突隔离、PIT未证明必须可区分。

## 3. PIT：两个时间轴，两个可声明的查询模式

沿用 source_available_at、provider_first_observed_at、snapshot_fetched_at，并补充
规范化/裁决版本的 recorded_at 与消费者 committed_at（由消费者提供）。经济期间不等于公开时间。
时间以有时区UTC存储，保留源精度；日期级公开时间不能伪造盘前时刻。

- **市场可知历史**：仅在精确源版本及公开时间有证据时，用该版本重建市场信息集。
  今天下载固定历史SEC accession可能支持重建，但今天的可变Yahoo最新值不支持。
- **系统实盘回放**：除公开时间外，还必须在当时已观察、制作、通过当时质量规则并发布。
  输入可用时间不得早于这些必要时间的最大值。不能把今天修好的解析结果当成当时已上线。
- 查询必须显式选择模式、knowledge cutoff和recipe/质量策略；模式不可静默切换。
- 派生值可用时间至少为所有输入可用时间的最大值；消费者按交易日历及cutoff决定first usable session。
- 历史缺少可验证时间/版本则PIT_UNPROVEN，研究默认拒绝；只能作为当前快照展示。
- 收盘后财报不能影响当天收盘决策；盘前、盘中、日期级披露分别测试。
  盘中估值也不能提前使用尚未形成的当日收盘价。

## 4. 纠错与SEC校验

SEC是披露源而非绝对正确的标签。分层判断，不能把跨源差异自动判为SEC错误：

1. 结构：concept/context/unit、维度、期间、单位倍数、有限值、重复冲突、报表覆盖。
2. 会计关系：适用时资产=负债+权益、现金变动桥、毛利关系、现金流分项加总。
   使用来源精度/四舍五入推导容差，声明适用条件；不同合并范围不强行配平。
   XBRL calculation linkbase只能作为部分证据，不完整不直接判错。
3. 期间：同一口径年度与独立季度/YTD桥接；53周财年、重分类和重述显式处理。
4. 原文对照：XBRL与同accession报表/附注对照；公告与10-Q差异先看期间/GAAP/并购/修订。
5. 异常检测：同比突变、符号或量级异常仅产生待核验标志，不能自动winsorize或修改源事实。

错误分类：OMD解析bug、源披露疑点、源正式修订、跨源口径冲突、未知。
解析bug：同一raw版本生成新adapter/normalized版本，保留旧结果及错误证据。
公司重述：新accession/公开时刻追加版本，不能改写重述前的信息集。
人工裁决：注入明确选择、原因和证据，独立有版本；严禁模型自行“合理化”金额。
待核验值可供标警展示；受影响的研究指标默认隔离，独立通过的字段不必全体作废。
质量规则升级也有时间版本，避免用未来质量判断悄悄筛掉历史样本。

## 5. 中性派生指标首批

先交付明确的 recipe：TTM营收/净利润、CFO−CapEx、同比、利润率、PE/PS/FPE。
规则先写契约再编码：
- TTM用四个独立季度或同口径FY+本期YTD−上年同期YTD；禁止重复累计，跨重述口径拒绝拼接。
- PS=当日公司总股权市值/当时可知TTM营收；PE分母为匹配股权归属的净利润。
- FPE=证券股价/同证券单位的预期EPS，保留FY1/NTM等预测期间、GAAP/调整后口径；亏损PE不作有效倍数。
- 股数有效日、披露日及股类/ADR比例必须匹配；缺公司总市值时不能用单股类市值替代。
- EV需明确债务、现金、少数权益/优先股及租赁政策，输入不足先缺失；列第二阶段。
- 不从PE×EPS反推出行情；不把预期营收当实际TTM营收。
- 币种不同默认不可算，显式FX政策需具备当时可用FX和来源；不隐式转换。

Rule of X、行业评分、因子选择/胜率与交易信号留在消费者；本计划不扩展经济研究结论。

## 6. 财报事件驱动更新

事件发现 → 去重排队 → 定向抓取 → 不可变快照 → 制作/校验 → 增量派生 → 发布候选。
轻量发现接口优先查询SEC申报索引/提交元数据；公告可早于10-Q，后续正式申报作为独立事件。
财报日历只是预计，不证明已发布。优先监听已确认发布事件；没有推送则有预算地轮询元数据。

事件键至少含provider、issuer、accession/源版本、event kind，状态：
DISCOVERED/QUEUED/FETCHING/VALIDATING/READY/QUARANTINED/RETRY_WAIT/FAILED。
事件、抓取请求、写入与消费确认均幂等；崩溃重启不能丢事件或重复发布。
确认不是财务修订的治理型10-K/A仍保留事件，但不强制重算无变化指标。
指数发现cursor与数据发布watermark分开；原子保存发现事件后再推进cursor。
使用重叠窗口和周期对账覆盖漏报、迟到、乱序与历史更正；不存在“没有事件就永远不校验”。

每日价格变更只更新对应日期的价格依赖指标；财报变更只重算相应发行人及证券映射的依赖。
一致预期独立变化即使没有财报也要更新；股数、拆股、汇率等有自己的事件。
修订影响范围依查询模式/有效区间决定，不能把修订传播到其公开前的历史。
显式历史回补任务与日常增量分离，恢复有cursor；长期无变更时只作轻量元数据对账。

## 7. 效率与出版边界

首个验证预算：8标的、每家最多1份10-K和1份10-Q；单份60秒，整批20分钟，SEC串行。
重试总次数最多3，仅限可分类瞬态错误，尊重Retry-After且受整批截止限制；schema错误直接隔离。
首版建议元数据轮询5分钟为可配置起点，由消费者决定窗口，遵守服务方最新限速。
演示历史面板只限上述名单合格证券（最多53候选）×5年日线、逐分区处理、单进程；内存预算512MB，超限停止并记录。
大规模运行先过代表样本门禁，不以增加timeout代替优化。

按issuer/证券/日期/版本索引增量依赖；列式向量化计算，禁止逐日期扫描整个财务历史。
结构断言：相同制作身份的重复事件0次重解析；仅当raw/fact_version、adapter/normalization版本、
schema及解析配置均未变时跳过解析。解析修复必须允许同raw产生新制作版本；
1发行人修订不扫描全部发行人；
缓存命中不下载报表；观测扫描行数、网络次数、解析次数、峰值内存及cold/warm耗时。
源码/测试只用合成fixture，私有原始数据不提交公共仓库。
OMD输出自包含immutable批次与manifest接口；消费者掌握真实路径、单writer、原子发布和GC。
旧批次保持可读，新批次未通过校验不可替换active指针；失败恢复不留下伪成功文件。

每家1份10-K/1份10-Q是首次探测预算，不保证TTM/YoY输入完整。
逐recipe检查同口径比较期间与accession血缘；不足明确缺失，不推算或伪称通过。
计算门禁需包含输入完整的代表样本；可使用已校验不可变快照或合成fixture。
额外历史回补单独列出所需accession及有界预算再执行，不无界扩抓。
