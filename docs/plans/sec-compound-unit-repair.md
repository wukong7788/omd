Preserve measure multiplicity and resolve each QName using its own in-scope namespace declarations, including default namespace and prefix rebinding.
- Canonical measures: use `iso4217:LOCAL` only for namespace `http://www.xbrl.org/2003/iso4217`; use `shares`/`pure` only for those local names in `http://www.xbrl.org/2003/instance`; represent every other expanded QName as `{namespace-uri}local` (empty namespace as `{}local`). Sort each measure list lexicographically while retaining repetitions. Standard USD, shares and pure simple units stay unchanged; compound `SecStatementRow.currency` remains `None`, never its numerator's currency. `unit_ref` and retained XML preserve source traceability.

Dispatch the complete source/package build to that exact supported version, compare all rebuilt output bytes, then issue the sealed production.
