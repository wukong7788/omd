# v0.1.3 vintage-plane migration

Install the optional `vintage-plane` extra to emit deterministic Parquet artifact bundles and import `EtfBenchmarkConstituentScope`, `EtfBenchmarkConstituentBundle`, `produce_etf_benchmark_constituent_vintages`, and `assemble_etf_benchmark_constituent_vintages` from `ohmydata.providers.tushare`. The registry types are exported from `ohmydata.core`.

The mapping projection adds canonical `etf_code`/`benchmark_index_code` aliases
while retaining legacy names. Statuses are fail-closed: current-only mappings,
unknown availability, and unproven weight retrieval are never historical PIT
facts. Consumers must supply their own cutoff/session/calendar policy; OMD does
not emit `first_usable_session` or strategy semantics. The producer accepts only
caller-created clients and explicit bounded requests, never credentials or
universe discovery.
